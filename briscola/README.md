# 🍋 Briscola Siciliana

Jeu de Briscola avec les cartes siciliennes (40 cartes) pour Android.

- 🤖 Jouer contre l'ordinateur
- 🌐 Jouer **en ligne avec un ami** : l'un crée une partie et reçoit un code à 5 lettres, l'autre le saisit dans « Rejoindre un ami ». Connexion directe (WebRTC via PeerJS), aucun serveur à installer.

## Construire l'APK
Onglet **Actions** → « Construire l'APK » → **Run workflow** → choisir la branche `briscola`. L'APK apparaît ensuite dans **Releases**.

## Règles
As 11 · 3 = 10 · Roi 4 · Cavalier 3 · Valet 2. Total 120 points, il faut plus de 60 pour gagner.

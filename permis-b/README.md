# Permis B Belgique (APK Android)

Application d'entraînement complète à l'examen théorique du permis B en Belgique.

- 📚 Cours : 16 chapitres (règles, signalisation, vitesses par région, priorités, dépassement, stationnement, autoroute, feux, alcool/GSM, sécurité, usagers vulnérables, véhicule, accident, distances, éco-conduite, permis et examens)
- 🚸 Catalogue de 40 panneaux belges dessinés + quiz
- ✏️ Entraînement par thème avec correction immédiate et explication
- 📝 Examens blancs : 50 questions aléatoires, 41/50 pour réussir, faute grave = −5, mode chronométré, correction complète
- 🎬 Perception des risques : 11 situations en vue conducteur, aléatoires, avec score selon le temps de réaction et revue du moment du danger
- ❌ Mes erreurs, 📊 statistiques, 🔊 lecture vocale des questions

Compilée automatiquement par GitHub Actions (onglet **Releases**). Application non officielle.

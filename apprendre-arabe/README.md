# تَعَلَّمِ العَرَبِيَّة — Apprendre l'arabe

Application Android pour apprendre l'arabe depuis le français :

- 🔤 **Alphabet** : les 28 lettres, leur prononciation, leurs 4 formes et un mot d'exemple
- ✏️ **Voyelles** : fatha, kasra, damma, soukoun, chadda, tanwin, voyelles longues + syllabes
- 📚 **Vocabulaire** : salutations, nombres, couleurs, famille, nourriture, animaux, corps, jours, phrases utiles
- 🃏 **Flashcards** et 🎯 **Quiz** avec score et meilleurs résultats
- 🔊 **Prononciation** via la synthèse vocale Android (voix arabe)

## Télécharger l'APK
Allez dans l'onglet **Releases** du dépôt et téléchargez `ApprendreArabe.apk`.
L'APK est recompilé automatiquement par GitHub Actions à chaque modification.

> Pas de son ? Paramètres Android › Synthèse vocale › Moteur Google › installer la voix **arabe**.
